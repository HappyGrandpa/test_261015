# 個人線上履歷專案 (Resume Template)

這是一個適合部署在 GitHub Pages 或作為個人履歷展示的開源專案範本。

## 專案結構
- `index.html`：履歷主要內容與語意化結構
- `style.css`：簡約現代的響應式樣式
- `.gitignore`：標準 Git 忽略設定檔

## 本地預覽
直接以瀏覽器開啟 `index.html` 即可瀏覽履歷效果。

## 如何發布到 GitHub Pages
1. 將此專案推送到你的 GitHub 儲存庫。
2. 進入儲存庫的 **Settings** -> **Pages**。
3. 在 **Branch** 選取 `main` 分支並儲存，即可獲得免費的線上履歷網址！
